# Frontend Features Structure

Thư mục này tổ chức mã nguồn theo mô hình Feature-driven cho các phân hệ nghiệp vụ tiếp theo của Campus Marketplace:

- `auth/`: Đăng ký, đăng nhập, xác thực OTP email sinh viên, upload minh chứng.
- `posts/`: Danh sách bài đăng, tìm kiếm, lọc, form tạo tin bán (SELL) và tin tìm mua (BUY_REQUEST).
- `chat/`: Giao diện trao đổi, danh sách cuộc trò chuyện, xem số điện thoại an toàn.
- `profile/`: Quản lý thông tin cá nhân, sở thích feed (`user_preferences`), lịch sử bài đăng.
- `admin/`: Quản lý duyệt hồ sơ sinh viên, xử lý báo cáo vi phạm (`reports`).
