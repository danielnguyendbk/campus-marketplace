3. [Architecture Decision Records (ADRs)](../decisions/): Các quyết định kiến trúc quan trọng đã được đồng thuận.
4. [API Documentation](../api/): Hợp đồng API v1.2 theo chuẩn OpenAPI 3.x.
5. [Business Rules](../business-rules/): Tài liệu quy tắc nghiệp vụ theo hồ sơ v1.2.
